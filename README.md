# Kalkulator Bunga Sederhana

Program ini digunakan untuk menghitung bunga sederhana berdasarkan rumus:

**Rumus:**
`Bunga = Pokok × Suku Bunga × Waktu`
`Total = Pokok + Bunga`

## Kolom Input
- **Pokok** → jumlah uang awal
- **Suku Bunga (%)** → persentase per periode
- **Periode Waktu** → lamanya waktu (tahun/bulan)

## Cara Penggunaan
1. Jalankan skrip `simple-interest.sh`
2. Masukkan nilai pokok
3. Masukkan suku bunga
4. Masukkan periode waktu
5. Hasil akan ditampilkan otomatis
